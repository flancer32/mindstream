# Цветовая интерпретация индикатора интереса

- Template Version: `20260619`
- Changed: `20260619`

## Назначение

Документ фиксирует прикладное браузерное правило цветовой интерпретации индикатора интереса в ленте публикаций.

Документ определяет:

- какое множество значений используется как локальная шкала интереса;
- как из этой шкалы выделяется верхний интервал повышенного интереса;
- как UI использует этот интервал для визуального ориентирования пользователя.

Документ не определяет алгоритм расчёта самих interest scores и не вводит серверную ответственность.

## Область действия

Правило применяется только в рамках текущей пользовательской ленты, видимой в браузере для одного пользовательского контекста.

Шкала цветовой интерпретации:

- строится заново для каждого актуального видимого набора публикаций на странице;
- зависит от текущих локально доступных значений индикатора интереса;
- не переносится между пользователями, страницами и состояниями ленты.

Под видимым набором публикаций понимается тот набор публикаций, который в текущий момент присутствует в DOM и визуально представлен пользователю на данной странице ленты.

## Локальное пространство значений

Для текущей страницы UI определяет:

- минимальное значение индикатора интереса среди всех публикаций текущего видимого набора;
- максимальное значение индикатора интереса среди всех публикаций текущего видимого набора.

Интервал между этими двумя значениями считается полным локальным пространством интереса для:

- данного пользователя;
- данного состояния interest vector;
- данной страницы публикаций.

Пример:

- минимальное значение: `69%`;
- максимальное значение: `82%`;
- локальное пространство значений: от `69%` до `82%`.

Если в текущем видимом наборе `min == max`, локальное пространство значений считается вырожденным, а все публикации этого набора трактуются как попадающие в верхний интервал интереса.

## Верхний интервал интереса

Из полного локального пространства выделяется верхний сегмент размером `20%` от всей ширины интервала.

Эквивалентная формулировка:

- нижние `80%` интервала считаются базовым диапазоном;
- верхние `20%` интервала считаются диапазоном повышенного интереса.

Порог вычисляется по формуле:

`threshold = min + (max - min) * 0.8`

Публикация попадает в верхний интервал интереса, если её значение индикатора:

- больше или равно `threshold`;
- меньше или равно `max`.

В вырожденном случае `min == max` порог равен этому же значению, поэтому все публикации текущего видимого набора попадают в верхний интервал интереса.

Пример для интервала `69% .. 82%`:

- ширина интервала: `13` процентных пунктов;
- порог верхних `20%`: `69 + 13 * 0.8 = 79.4%`;
- публикации со значением `79.4%` и выше относятся к наиболее интересным в рамках данной страницы.

## Визуальное правило

Индикатор интереса окрашивается в зелёный цвет для всех публикаций, попадающих в верхний интервал интереса.

Остальные публикации:

- не считаются наиболее интересными в рамках данной страницы;
- не получают зелёную маркировку только на основании значения индикатора.

Зелёный цвет в данном правиле означает не абсолютный глобальный уровень интереса, а относительное попадание в верхний локальный диапазон текущей страницы.

## Смысл для пользователя

Цветовая интерпретация служит визуальным ориентиром и помогает быстро выделить публикации, которые в текущем наборе выглядят наиболее соответствующими интересам пользователя.

Правило:

- не объясняет причины конкретной оценки;
- не заменяет процентное значение индикатора;
- не обещает объективную важность публикации вне текущего локального набора.

## Границы документа

Документ:

- относится только к браузерной композиции UI;
- не требует участия бэкенда;
- не фиксирует CSS, DOM-структуру, имена компонентов или технологию реализации.
